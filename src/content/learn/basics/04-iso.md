ISO，是相机传感器对光的**敏感程度**。

和光圈、快门不同，ISO 不控制进光量，它控制的是传感器"对光有多敏感"。

## ISO 怎么表示

ISO 用数字表示，常见的有：

`ISO 100  ISO 200  ISO 400  ISO 800  ISO 1600  ISO 3200  ISO 6400  ISO 12800`

规律很简单：

- ISO 越低（比如 ISO 100）→ 传感器越不敏感 → 照片越暗
- ISO 越高（比如 ISO 3200）→ 传感器越敏感 → 照片越亮

每差一档，亮度差一倍。ISO 200 的亮度是 ISO 100 的两倍，ISO 400 是 ISO 200 的两倍。

## ISO 的代价：噪点

如果 ISO 高了就能拍亮，那为什么不全都用 ISO 12800？

因为**高 ISO 有代价：噪点**。

你可以把 ISO 理解成"放大信号"。ISO 越高，传感器把光信号放得越大，但同时，信号里的杂音也一起被放大了——这些杂音就是噪点。

噪点长什么样？就是照片里那些颗粒感、彩色小点，让画面看起来不干净。

- **低 ISO（100-400）**：画质干净，几乎看不到噪点
- **中 ISO（800-1600）**：有轻微噪点，但不影响看
- **高 ISO（3200+）**：噪点明显，画质下降

现在的相机高感越来越好了，很多全画幅相机 ISO 3200 都挺干净。但不管多好的相机，ISO 越高画质越差，这个规律不变。

## 三要素的联动

现在我们把三个要素放在一起看：

| 参数 | 变大时 → 照片 | 代价 |
|------|-------------|------|
| 光圈 f 值（变大 = 光圈变小） | 变暗 | 景深变大（更清晰） |
| 快门速度（变大 = 更快） | 变暗 | 能凝固更快的动作 |
| ISO（变大） | 变亮 | 噪点变多 |

曝光的核心逻辑是：**三个参数一起决定了照片的亮度**。

比如你想要一张亮度合适的照片，可以有很多种组合：

- f/2.8 + 1/500s + ISO 100
- f/4 + 1/250s + ISO 100
- f/4 + 1/500s + ISO 200

这些组合出来的照片亮度差不多，但画面效果不一样——有的虚化强、有的能凝固动作、有的画质干净。

> 摄影的技术部分，说白了就是在这三个参数之间做取舍。

## 实用原则

新手记住一句话：**ISO 能低就低**。

在光线足够的情况下，尽量用低 ISO（比如 100 或 200），保证画质。只有当光圈已经开到最大、快门已经慢到安全快门以下了，再去提高 ISO。

这是个很实用的优先级：

1. 先确定你要的光圈（要不要虚化）
2. 再确定快门（够不够安全快门）
3. 最后调 ISO 让亮度合适

## 一个小练习

找一个光线不太好的室内场景。

分别用 ISO 100、ISO 800、ISO 3200 各拍一张（调整光圈快门让亮度差不多），然后放大到 100% 看，对比一下噪点的区别。

亲眼看一次，比什么都直观。

# 需求沟通记录 #001 — 网站定位与内容规划

日期：2026-08-12

## 项目概述
做一个关于相机的说明网站，定位是：**新手入门教程 + 带作品展示的个人摄影站**。

---

## 一、教学部分

| 问题 | 回答 |
|------|------|
| 目标读者 | 刚买相机的人 |
| 内容深度 | 会深入到后期、布光、题材专攻这种进阶内容 |
| 内容形式 | 文字 + 配图 |
| 章节组织 | 学习路径 + 知识领域分类 都要有（混合式） |

### 知识体系初步框架（从之前的讨论中提炼）

1. **基础概念**：曝光三要素（光圈/快门/ISO）、曝光补偿/EV、测光模式、焦距与视角、对焦
2. **构图与视觉语言**：经典构图法、景别、画面层次
3. **光线**：光的方向、自然光时段、人工光基础
4. **不同题材拍法**：人像、风光、街拍、静物/美食、运动、夜景
5. **相机操作**：模式转盘（P/A/S/M）、白平衡、照片风格/胶片模拟、RAW vs JPEG、保养
6. **后期基础**：LR/PS 常用调整、曝光/对比度/色彩/锐化、二次构图
7. **器材认知**：相机分类、镜头体系、配件

## 二、作品展示部分

| 问题 | 回答 |
|------|------|
| 作品分类 | 按题材（人像/风光/街拍…）、按时间、按项目 —— 多种分类方式都要有 |
| 照片信息 | 相机型号、镜头、参数（光圈/快门/ISO）、拍摄地点、拍摄时间、一句话描述 |
| EXIF | 需要自动读取 |
| 浏览模式 | 大图瀑布流 / 画廊式 与 按相册/项目分组 可以切换 |

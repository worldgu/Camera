很多新手第一次打开 Lightroom，看到右边一排滑块就懵了：这么多东西，从哪儿动手？

其实修一张照片有固定顺序，跟着走就不会乱。
这一篇讲清楚这个顺序，以及每个滑块到底在干什么。

## 为什么修图要按顺序

因为**后面的调整会依赖前面的结果**。

比如你先把饱和度拉高，再去调白平衡，颜色会全乱，得重新调饱和度。
反过来先定白平衡再调饱和度，就是一次到位。

标准顺序是：**先整体，后局部；先影调，后颜色；锐化和降噪放最后。**

## 第一步：把 raw 导进来

Lightroom 的逻辑是「目录 + 原图」，它不改你的原始文件，所有调整都记在目录里。
这意味着你随时可以点「复位」回到最初，非常安全。

导入时记两件事：

- 选「添加」而不是「复制」，除非你想让 Lightroom 帮你搬文件
- 建立按日期或按主题的文件夹习惯，不然半年后你找不到任何一张片子

## 第二步：白平衡定颜色底子

白平衡就两个滑块：**色温**（蓝到黄）和**色调**（绿到品红）。

新手最实用的做法：用白平衡吸管点画面里应该是中性灰或白色的地方，
比如白墙、白衬衫、水泥地。点完基本就八九不离十了。

然后根据感觉微调：

- 想让画面暖一点、有黄昏感 —— 色温往右
- 想让画面冷一点、有清晨或都市感 —— 色温往左
- 人的皮肤发绿 —— 色调往品红加一点

白平衡没有绝对正确答案，它是表达工具。同一张日落片，调冷是清冷，调暖是热烈。

## 第三步：曝光与影调六个滑块

这六个滑块管的都是明暗，但管的范围不一样：

| 滑块 | 管什么 | 什么时候动 |
|------|--------|-----------|
| 曝光 | 整张照片的整体亮度 | 照片整体偏暗或偏亮 |
| 对比度 | 亮暗差距的大小 | 画面发灰、不通透 |
| 高光 | 偏亮的那部分 | 天空过亮、细节丢了 |
| 阴影 | 偏暗的那部分 | 暗部黑成一团、想找回细节 |
| 白色 | 最亮的那个点 | 定义画面的亮部上限 |
| 黑色 | 最暗的那个点 | 定义画面的暗部下限 |

新手最常用的组合，叫「HDR 味」的反面操作：
**降高光 + 提阴影**能救回大光比的照片，但拉太狠画面会发灰、假。
提完阴影记得把黑色往左压一点，让暗部重新扎下去，照片才有筋骨。

判断标准不是滑块数字，而是**直方图**：左右两端没有大片贴边（没有大面积死黑和死白），
中间的山有起伏而不是挤成一坨，这张的影调就成了。

## 第四步：颜色

**鲜艳度和饱和度的区别**：饱和度是把所有颜色一起加，容易让本来就艳的地方溢出；
鲜艳度只加那些不够艳的颜色。新手优先用鲜艳度，更安全。

**HSL 面板**是精修颜色的地方，三个维度：

- 色相（H）：把某个颜色往另一个颜色偏，比如把偏黄的草地往绿色拉
- 饱和度（S）：单独控制某个颜色的浓淡，比如只降低红色，让皮肤不那么红
- 明亮度（L）：单独控制某个颜色的明暗，比如压暗蓝色让天空更深邃

最常用的两个 HSL 操作：压暗蓝色让天空有分量；降低橙色饱和度并提亮它，让皮肤干净通透。

## 第五步：局部调整

全局滑块改的是整张照片，但很多时候你只想改一块。

三个工具：

- **渐变滤镜**：从一边往另一边渐变，压天空最常用
- **径向滤镜**：一个椭圆范围，做局部提亮或者暗角
- **画笔**：手动涂哪儿改哪儿，最灵活

新版 Lightroom 还有**智能蒙版**（选择主体、选择天空、选择人物），
一键把天空或人抠出来单独调，新手用起来非常省事。

局部调整的原则：**能不明显最好**。别人看出你修过某一块，就说明修过头了。

## 第六步：细节与收尾

- **锐化**：默认的 40 左右够用了，具体见锐化那篇
- **降噪**：高 ISO 的照片才需要，压太多画面会发蜡
- **镜头校正**：勾上「删除色差」和「启用配置文件校正」，能自动修畸变和暗角
- **裁切**：见二次构图那篇

## 一个提速技巧：同步设置

同一场景拍了二十张，不用一张张修。

修好第一张，全选其余的，点右下角「同步」，勾上要同步的项目，一次搞定。
白平衡和镜头校正非常适合同步，局部调整就别同步了（每张主体位置不一样）。

## 动手练一下

挑一张你拍得不太满意的 raw：

1. 先用吸管点一下画面里的白色物体，看白平衡变了多少
2. 只动曝光，把整体亮度调到舒服
3. 降高光看天空的细节能回来多少，提阴影看暗部能找回多少
4. 把黑色滑块往左压，感受画面「立起来」的那一下
5. 用鲜艳度加 15，再用饱和度加 15，对比这两者的区别
6. 最后点几次「复位」和「撤销」，对比修前修后

## 速查表

| 问题 | 动哪个 |
|------|--------|
| 整体偏暗 | 曝光 |
| 画面发灰不通透 | 对比度 + 黑色往左 |
| 天空过曝没细节 | 高光往左 |
| 暗部黑成一团 | 阴影往右 |
| 颜色偏黄 / 偏蓝 | 色温 |
| 皮肤发红 | HSL 里降红 / 橙饱和度 |
| 天空不够蓝 | HSL 里压暗蓝色明亮度 |
| 只想压一边的天空 | 渐变滤镜 |

---

后期不是把照片变成另一张照片，而是把你当时看到的那个感觉还原出来。
滑块记不住没关系，顺序记住就行。

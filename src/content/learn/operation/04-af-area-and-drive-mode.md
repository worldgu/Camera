对焦模式（AF-S / AF-C）决定的是"什么时候锁焦"，基础篇已经讲过。

这一篇讲另外两个转盘：**对焦区域**决定相机在画面的哪块地方找目标，**驱动模式**决定按一次快门拍几张。这两个配好了，相机才算跟手。

## 对焦区域有几种

从小到大，实际就是"你替相机决定多少"的差别：

**单点**。一个小方框，只对这一块。最精确、最可控，也最需要你自己把框放对位置。

**扩展点**。以中心点为主，周围几个点辅助。目标略微移出中心时还能咬住，适合有点动但不剧烈的对象。

**区域 / 分区**。给出一片矩形范围，相机在这片里自己找主体。适合运动方向大致可预测的场景。

**广域 / 全画面**。整个画面自动找，通常优先找离得近的、对比强的、以及人脸。快，但会抢焦。

**追踪**。先指定一个目标，之后它在画面里怎么跑，框就跟着它走。

选择原则就一句：**主体越好预测，用越小的区域。**

## 人眼和主体识别

现在的机身基本都有人脸和人眼识别，很多还能识别动物、鸟、车。它是对焦区域之上的一层，开着通常只有好处。

几个实际经验：

**拍人常开人眼识别**。它比你手动挪点准得多也快得多。注意可以设置优先左眼还是右眼，侧脸时这个设置影响明显。

**戴口罩、侧背、逆光剪影时会失效**，此时相机会退回普通对焦逻辑，最好手动切回单点。

**识别对象要选对**。拍鸟却开着"人物"，相机会一直在画面里找人。

**拍非人主体时关掉它**。拍静物、拍街景，画面里有个路人就会把焦点抢走。

## 驱动模式怎么配

**单拍**。按一次拍一张。风光、静物、慢节奏抓拍用它，避免误连拍出一堆废片。

**低速连拍**。每秒三到五张。表情、动作有变化但不剧烈的场景很合适，选片余地够，废片不算多。

**高速连拍**。每秒十张以上。体育、鸟飞、孩子跑、宠物必需。代价是缓存和存储卡压力大，回来选片也是体力活。

**自拍延时**。两秒挡在三脚架长曝时最实用，能消掉按快门的手震；十秒用来自己入画。

**电子快门连拍**。速度可以很夸张，但要注意果冻效应（快速横移时画面变形）和某些人工光源下的条纹。

连拍必须配 **AF-C** 才有意义。用 AF-S 高速连拍，等于把第一张的焦点复制十遍。

## 让操作变顺的几个设置

**背钮对焦**。把对焦从快门按钮上拆下来，交给机背的一个按钮（通常是 AF-ON）。快门只管拍。

好处是对焦和拍照彻底分离：按住背钮就是连续对焦，松开就锁住焦点，可以随便重新构图再拍。习惯了很难回去。

**对焦点位置记忆**。竖拍和横拍常常需要不同的对焦点位置，很多机身能分别记住，值得打开。

**摇杆或触摸屏选点**。用方向键挪点太慢，摇杆或者点屏幕快得多。

**AF/MF 快速切换键**。微距、隔着栏杆拍、极暗环境这类自动对焦无能的场合，能一键切手动很关键。

**峰值对焦和放大辅助**。手动对焦时的两个救命功能：峰值把合焦的边缘描亮，放大让你看清细节。

**对焦点数量减少**。可选点太多反而挪不到位，很多机身能限制成较少的点，操作明显变快。

## 常见场景怎么配

| 场景 | 对焦模式 | 对焦区域 | 驱动模式 |
|------|----------|----------|----------|
| 静物 / 商品 | AF-S | 单点 | 单拍 |
| 风光 | AF-S | 单点 | 单拍（三脚架配两秒延时） |
| 摆拍人像 | AF-S 或 AF-C | 单点 + 人眼识别 | 单拍或低速连拍 |
| 街头抓拍 | AF-C | 区域 | 低速连拍 |
| 儿童 / 宠物 | AF-C | 追踪 + 对象识别 | 高速连拍 |
| 体育 / 鸟飞 | AF-C | 区域或追踪 | 高速连拍 |
| 夜景长曝 | MF 或 AF-S | 单点 + 放大辅助 | 两秒延时 |
| 微距 | MF | 单点 + 峰值 | 单拍 |

## 一个小练习

找一个朝你走过来的人（或者让朋友配合），拍两组。

第一组：AF-S + 单点 + 单拍。第二组：AF-C + 追踪 + 低速连拍。

回来看合焦率。第一组大概只有第一张准，第二组大部分都能用。**这个差距不是器材造成的，是设置造成的**，而它只花你半分钟去改。

然后把第二组这套参数存进自定义档位，下次遇到会动的东西一键切换。

---

对焦区域和驱动模式是最容易被留在出厂默认的两项，也是改一次就长期受益的两项。规律很简单：**主体越好预测就用越小的区域，主体会动就把 AF-C 和连拍一起打开。** 剩下的就是把常用组合存成自定义档，让切换只花一秒。

买完机身和镜头，店员一般会顺势推一堆配件：UV 镜、清洁套装、专用包、屏幕膜、快装板、闪光灯。

其中确实有几件缺了就出不了片，也有几件放在柜子里三年都不会拆封。这一篇按优先级排一遍。

## 立刻就要的两件

**存储卡**。别买最便宜的杂牌，也别追最贵的规格。看两个数字：容量和写入速度。

拍照选 64G 或 128G 就够，比一张 512G 更稳妥——万一卡坏了，损失是一部分而不是全部。写入速度要跟得上你的连拍和视频：只拍照片，UHS-I U3 足够；要录 4K 或者高速连拍，看清机身要求的最低速度再买。

关键是**别买假卡**。存储卡是假货最集中的品类，认准正规渠道，到手用软件测一次实际读写速度。

**备用电池**。微单的电子取景器和屏幕很耗电，标称续航常常拍不到一半。一块副厂电池的钱不多，但能决定你下午还拍不拍得下去。

副厂电池的风险主要在虚标容量和触点接触，选口碑好的品牌即可，不必迷信原厂。

## 很快就会用到的

**气吹和镜头布**。最便宜也最高频。镜头前有灰先用气吹，吹不掉再用布，别一上手就拿衣角擦——沙粒会在镀膜上划出永久痕迹。

**一个能真背出门的包**。不必是相机专用包，任何有缓冲隔层、你日常愿意背的包都行。**这件事的判断标准只有一个：会不会因为嫌麻烦而不带相机。**

**一根结实的背带**。原厂织带常常又硬又滑。换一根宽一点、带防滑的，脖子和手腕会舒服很多，也降低摔机风险。

## 按题材再决定的

**三脚架**。拍夜景、长曝光、星空、延时的必需品，其他题材大部分时间是负担。

买的时候记住一句：**能稳住你最重的那套器材，才叫三脚架**。太轻的碳纤维小架子在风里抖起来，等于白扛。如果只是偶尔用，先买中端铝合金；如果经常徒步带上山，再考虑碳纤维减重。云台优先选带阻尼的球台，比三维云台上手快。

**CPL 偏振镜**。真正有效果、软件替代不了的滤镜。它能压掉水面和玻璃的反光、加深蓝天。拍风光值得配一片，注意转动角度才有效，广角端可能出现天空不均匀。

**ND 减光镜**。白天想拍流水丝滑、云层拉丝，必须靠它减光。常用 ND8 到 ND1000。可变 ND 方便但廉价款容易出现十字暗斑。

**反光板**。拍人像时补暗面最便宜的方案，五合一的折叠款很轻，缺点是需要有人帮你举。

**闪光灯**。室内人像、活动记录会用到。买了以后第一件事是学会跳闪打天花板，直打正脸的效果通常很难看。

## 可以先不买的

**UV 镜**。数码时代它对画质没有帮助，唯一作用是当保护镜。如果你确实常在沙尘、海边、孩子伸手可及的环境拍摄，买一片镀膜好的当保护也行；但廉价 UV 镜会带来逆光鬼影和轻微降质，宁可不装。

**原厂专用相机包**。价格常常翻倍，功能未必比普通包好。

**遥控快门**。多数机身已有 App 遥控和延时自拍，够用了。

**贴屏幕钢化膜、机身贴皮**这类，纯个人喜好，跟出片无关。

## 配件优先级速查

| 配件 | 优先级 | 说明 |
|------|--------|------|
| 存储卡 | 必需 | 64G 或 128G，认渠道防假卡 |
| 备用电池 | 必需 | 微单尤其需要，副厂可用 |
| 气吹 + 镜头布 | 高 | 几十块解决日常清洁 |
| 能背出门的包 | 高 | 标准是你愿意天天带 |
| 舒适背带 | 高 | 减负同时降低摔机风险 |
| 三脚架 | 看题材 | 夜景长曝必需，先看承重 |
| CPL 偏振镜 | 看题材 | 消反光，后期无法替代 |
| ND 减光镜 | 看题材 | 白天长曝必需 |
| 反光板 | 看题材 | 人像补光最省钱的办法 |
| 闪光灯 | 看题材 | 室内活动，务必学跳闪 |
| UV 镜 | 低 | 只当保护镜，廉价款反而扣分 |
| 遥控快门 | 低 | 机身 App 和延时自拍已够 |

## 一个小练习

把你打算买的配件列成一张清单，然后逐条问一句：**没有它，我这个月计划拍的照片有哪几张拍不成。**

答得出具体照片的，留下；答不出的，划掉。划掉的钱先攒着。

攒够一支定焦的钱时你会发现，一支好镜头带来的画面变化，比十件配件加起来都大。

---

配件的作用是清除障碍，不是提升画质。**先把存储卡和电池这类会直接打断拍摄的东西补齐，其余的等到某次拍摄真的被卡住了，再针对性地买。**

# Camera 摄影站 说明文档

## 项目简介

面向摄影新手的教程站，同时作为个人作品集。极简黑白风格，支持深浅色切换。
需求详见 [需求文档.md](./需求文档.md)。

- 线上地址：https://worldgu.github.io/Camera/
- 部署方式：GitHub Actions 自动构建，推送 `main` 分支即发布

## 技术栈

| 项目 | 选型 |
|------|------|
| 框架 | Astro 7（静态输出） |
| 交互组件 | React 19（仅作品画廊使用） |
| 样式 | 原生 CSS（`src/styles/global.css` + 组件内联样式） |
| 内容 | Markdown 内容集合（教程）+ JSON（作品、装备） |
| 部署 | GitHub Pages，子路径 `base: '/Camera'` |

## 出图能力

项目内置了火山方舟 Seedream 的调用脚本，用于生成首页 hero、作品占位图、
教程示意图等网站用图。工具路径：`scripts/ark_image.py`，只用 Python 标准库，
零依赖。

### 配置

```bash
export ARK_API_KEY="ark-xxxxxxxx"
```

API Key 优先级：`--key` 参数 > 环境变量 `ARK_API_KEY`。不要把 Key 提交到仓库。

### 常用命令

```bash
# 生成首页 hero（横版 16:9，2560x1440）
python3 scripts/ark_image.py -p "提示词" --size 16:9 -o public/images/hero.jpg

# 生成方图
python3 scripts/ark_image.py -p "提示词" --size 1:1 -o output/square.jpg

# 图生图（参考本地文件）
python3 scripts/ark_image.py -p "换成夜景" --image ref.jpg --size 4:3 -o out.jpg

# 生成多张变体
python3 scripts/ark_image.py -p "提示词" -n 4 -o output/var.jpg
```

### 关键约束

- 模型：`doubao-seedream-5.0-lite`
- 像素下限：**总像素 >= 3,686,400**，低于此数会报 `InvalidParameter`
- 推荐尺寸映射：
  - 16:9 → 2560 × 1440
  - 9:16 → 1440 × 2560
  - 1:1 → 2048 × 2048
  - 4:3 → 2496 × 1664
  - 3:4 → 1664 × 2496
- 返回的 TOS 链接 24 小时过期，脚本会自动下载到本地

### 其他路线对照

| 路线 | 状态 | 备注 |
|------|------|------|
| 火山方舟 Seedream | 可用 | 本项目主路线，脚本已就位 |
| Codex 内置 image_gen | 不可用 | 当前环境未加载 |
| OpenAI CLI (gpt-image-2) | 不可用 | 需要 OPENAI_API_KEY + openai 包 |

## 开发环境

要求 Node 22（与 CI 一致）。

```bash
npm install        # 安装依赖
npm run dev        # 本地开发，默认 http://localhost:4321/Camera/
npm run build      # 构建到 dist/
npm run preview    # 预览构建产物
```

注意 `base` 是 `/Camera`，本地访问也必须带这个前缀，直接开 `localhost:4321` 会 404。

## 访问统计配置

统计走 Google Analytics，通过环境变量 `PUBLIC_GA_ID` 控制，只在生产构建时注入脚本：

- 本地：把 `.env.example` 复制为 `.env`，填入 `G-XXXXXXXXXX`
- 线上：在 GitHub 仓库 Settings → Secrets and variables → Actions → Variables 添加 `PUBLIC_GA_ID`

未配置时构建产物里不含任何统计脚本，可用 `rg googletagmanager dist` 验证。

## 内容维护

新增教程：在 `src/content/learn/basics/` 下加 Markdown，frontmatter 字段见
`src/content.config.ts`（`title`、`description`、`category`、`order`、`date`、`tags`）。
frontmatter 里没有 `slug` 字段，URL 由文件名去掉数字前缀和 `.md` 生成，统一走
`src/utils/slug.ts` 的 `slugOf()`。学习路径页、分类索引页和详情页的 `getStaticPaths`
必须都用这个函数，否则链接会和实际路由对不上。

新增教程图解：正文里直接写 `<figure class="diagram">` 包一个内联 `<svg>`，末尾配
`<figcaption>` 说明。SVG 里不要写死颜色，只用 `global.css` 里定义好的 class：
`dia-stroke`（主描边）、`dia-stroke-thin`（辅助线）、`dia-fill`（实心主体）、
`dia-fill-soft`（浅底色块）、`dia-text` / `dia-text-muted` / `dia-text-label`（三级文字）。
这些 class 都绑在 CSS 变量上，深浅色主题才会跟着一起变。`viewBox` 请用相对坐标并配
`role="img"` + `aria-label`；宽度交给 CSS 的 `max-width: 100%`，不要写死 `width`，
否则手机端会溢出。示例见 `02-aperture.md`、`03-shutter-speed.md`、`08-focal-length.md`。

新增作品：往 `src/data/works.json` 追加一条，`slug` 唯一。目前没有真实图片，靠
`color` + `aspectRatio` 生成 CSS 渐变占位图。

新增器材：往 `src/data/gear.json` 追加一条。`status` 取 `active` / `retired` /
`wishlist`，`type` 取 `camera` / `lens` / `support` / `light` / `filter` /
`storage` / `bag`。`matchCamera`、`matchLens` 的值要和 `works.json` 里的
`camera`、`lens` 字符串完全一致，装备详情页靠它反查关联作品。

## 已知缺口

- 全站没有真实照片，作品与器材图都是 CSS 渐变占位
- EXIF 自动提取未实现（CI 无 exiftool 步骤），作品参数目前手写在 JSON 里
- 教程图解只做了 3 篇（02 光圈、03 快门、08 焦距），余 6 篇待补（清单见需求文档 6.3）
- i18n 未预留，文案硬编码在各页面模板中

## 维护约定

- lockfile 请用 Node 22 配套的 npm 10 生成。npm 11 会按当前平台裁剪 lockfile，
  删掉 Linux 才需要的 `@emnapi/*` 等条目，导致 CI 的 `npm ci` 报 not in sync。
- 站内链接不要手拼，教程走 `slugOf()`，作品和器材用数据里的 `slug` 字段。

同样的预算，二手能买到高一到两个档位的器材。对新手来说这是最划算的入门方式，前提是你知道该看什么。

二手器材的风险其实很集中：**机身怕维修史和快门数，镜头怕霉和进灰**。把这几项查清楚，成功率就很高了。

## 先定预算再看货

顺序不能反。先想清楚要什么画幅、什么焦段（见前两篇），再去搜对应型号的近期成交价。

参考价怎么找：在二手平台按型号搜索，**看已成交的价格，不要看在卖的挂价**。挂价普遍虚高，成交价才是市场真实水平。多看十条成交记录，你就有了议价底气。

一个经验：**明显低于市场价的机器，一定有原因**。可能是进过水、换过传感器、快门接近寿命，也可能压根是骗局。低两成可以聊，低五成基本不用看。

## 机身要查什么

**快门数**。相机快门有机械寿命，入门机通常标称十万次，中高端二十万到五十万次。查法有两个：机内菜单（部分品牌支持），或者用相机现场拍一张 RAW，导入查看 EXIF 的快门次数字段。

**注意别只信卖家口头说的数字。** 现场拍一张现场读，是唯一可靠的方式。

快门数怎么看：不到标称寿命一半的都算健康。接近寿命也不是不能买，但价格要压下来，并且明白随时可能需要更换快门组件。有电子快门的机身情况会宽松一些。

**维修史与进水**。观察机身底部和电池仓的螺丝，原厂出厂的十字槽是完整的，被拆过会留下毛刺或滑丝。电池仓内、卡槽内如果有白色粉末或锈迹，很可能进过水或长期高湿存放，直接放弃。

**传感器坏点与灰尘**。把光圈缩到最小（比如 F16 以上），对着一面均匀的白墙或天空，手动对焦到失焦状态拍一张，然后放大看。**固定位置的黑点是传感器灰尘，可以清洗；固定位置的彩色亮点是坏点，洗不掉。** 少量坏点对拍照影响不大，但可以作为压价的理由。

**屏幕与取景器**。检查有无划痕、亮线、进灰。翻转屏要来回翻几次，看排线是否松动。

## 镜头要查什么

镜头比机身更值得仔细看，因为最贵的毛病是无法逆转的。

**霉斑**。这是镜头的头号杀手。用手电从镜头前端斜着照进去，同时从后端观察，霉斑呈白色絮状或蛛网状，长在镜片表面或胶合层里。轻微边缘霉对成像影响有限，但会继续扩散；中心霉直接放弃。

**灰尘**。用同样的打光方式看，灰尘是清晰的小颗粒。**少量灰尘对画质几乎没影响**，是正常使用痕迹，不必因为几粒灰放弃一支好镜头。

**镀膜与划痕**。斜着看镜片表面反光是否均匀，有大面积擦拭痕迹说明前主人清洁方式粗暴，逆光时容易出现眩光和对比度下降。

**对焦与变焦手感**。自动对焦装机身上全程拉一遍，听有无咔咔异响、有无跑焦。手动对焦环应当阻尼均匀，不能松垮或卡顿。变焦环推拉要顺滑，如果自己会往下垂（俗称变焦滑落），说明内部磨损明显。

**光圈叶片**。取下镜头对着光，用机身或镜头拨杆收放光圈，叶片应当开合利落、形状规整。有油渍或者开合迟滞的，是典型的老镜头故障。

**防抖**。有 IS / OSS / VC 这类标识的镜头，开关打开后半按快门，取景器画面应当明显稳定，同时听得到轻微的运转声。

## 交易环节的风险

**优先当面交易**。带上自己的存储卡和电池，现场装卡实拍。远程邮寄务必走平台担保，全程录像开箱。

**索要购买凭证**。有原始发票的机器，来源更可靠，还可能剩余保修期。

**警惕的几种话术**：说"电池落家里了，没法开机试"，说"只在家里用过没出过门"却快门数很高，说"急出所以便宜"并催你快速转账。这几种都值得直接放弃。

**留出维修余量**。二手不保修，买的时候心里给一笔预算，用于清洗传感器或更换快门。把这笔钱算进去再判断值不值。

## 各类问题的处置速查

| 发现的问题 | 严重程度 | 建议 |
|------------|----------|------|
| 机身掉漆、磨痕 | 轻 | 不影响成像，可作压价理由 |
| 少量镜头进灰 | 轻 | 正常痕迹，可以买 |
| 传感器灰尘 | 轻 | 清洗即可，压价 |
| 几个传感器坏点 | 中 | 影响有限，明显压价 |
| 快门数过半 | 中 | 压价，并预留换快门预算 |
| 变焦环滑落 | 中 | 内部磨损，能用但会加剧 |
| 边缘轻微霉斑 | 中偏重 | 会扩散，除非极便宜否则放弃 |
| 中心霉斑 | 重 | 直接放弃 |
| 光圈叶片有油、迟滞 | 重 | 维修成本高，放弃 |
| 螺丝有拆卸痕迹 | 重 | 维修史不明，放弃 |
| 电池仓锈迹、白粉 | 重 | 疑似进水，放弃 |

## 一个小练习

不必真的买，先做一次市场调研。

挑一台你感兴趣的型号，在二手平台翻二十条记录，把每条的价格、快门数、成色描述记下来。

做完你会发现三件事：这个型号的合理价格区间在哪里，哪些卖家的描述明显含糊，以及同样成色的价格能差出多少。

这份表格是你真正去谈价时最有用的东西。

# 需求沟通记录 #003 — 架构与交互细节

日期：2026-08-13

## 本次确认的事项（共 10 项）

### 🔴 架构相关

1. **图片存储**：先存放在 git 仓库里（图片不多的前提下），后期满了再迁图床

2. **EXIF 提取**：GitHub Actions 构建时自动扫描新图提取 EXIF，写入元数据文件

3. **URL 结构**：
   - 教程：`/learn/{category}/{slug}`，如 `/learn/basics/aperture`
   - 作品：`/works/{slug}`，如 `/works/mountain-sunset`

### 🟡 交互体验

4. **作品列表交互**：
   - 滚动加载更多（无限滚动）
   - 点击以灯箱弹窗查看（不离开列表页）
   - 鼠标悬停什么都不显示（保持画面干净）

5. **教程配图**：示意图 / 图解风格（第一版可先用占位图）

6. **导航方式**：汉堡菜单（首屏更干净，画廊感强）

### 🟢 功能增减

7. **暗色 / 亮色切换**：需要（黑白风格下的深浅两种基调）
8. **评论系统**：不要
9. **访问统计**：需要（Google Analytics 或同类）
10. **社交分享**：需要（教程 + 作品页）
